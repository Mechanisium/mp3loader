# mp3loader



A no fuss ytdlp Wrapper for mp3 files.
Simple,Fast,Repeatable,Accurate and works everytime.
this is the one and only mp3 downloader that i personally crafted for my use
primarily uses ytdlp (you need to either have ytdlp on your system or its 
standalone executable in this directory).

<video src="https://github.com/Mechanisium/mp3loader/blob/main/sample_clip/sampl.webm" controls="controls" style="max-width: 100%;"></video>


the purpose of this project is to save you headache from all those options and
arguments that ytdlp requires to download a simple file and saves you a visit 
to those yt to mp3 sites that are slow and full of ads. 
there are 3 versions of this projects:

singles.py               => super minimal, drop link enter repeat.
playlists.py             => download a playlist automatically. drop link , let it ring
pythonscript-combined.py => interactive. lets you choose from single or playlist. just a few extra steps
